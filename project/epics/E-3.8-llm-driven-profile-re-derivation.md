## Goal

Replace the deterministic N-010 profile with Tier-M LLM-driven derivation, project-tagged priors, per-project overrides, and a 'what you've learned' UI. The restart audit found the MVP profile is an empty backend — `profile.py` and four `api/profile.py` endpoints exist, but no code path emits an event, `frontend/src` has zero references and the profile has never been derived (landscape §3) — so this epic now starts by making the existing backend real: wire the emitters and derive at job end in Phase 2, then build the UI and the LLM re-derivation in Phase 4 once ≥ 20 jobs of events exist.

## Scope

- S-3.8.3 — wire the approve / refine / publish / cancel / effort-override emitters, derive at job end; UI half (New Project pre-fill, Settings reset) as a second acceptance group (Phase 2 item 14 / Phase 4)
- S-3.8.2 — "what you've learned" UI surface, read-sites on New Project and Settings (Phase 4)
- S-3.8.1 — Tier-M LLM-driven derivation + project-tagged priors + per-project temporary overrides, after ≥ 20 jobs (Phase 4)

## Out of scope

- Feedback-driven auto-tuning of curation thresholds (D-045: human-in-the-loop until ≥ 50 decision-level items across ≥ 5 trips — E-3.10's golden set is the instrument); multi-turn conversational refinement (E-4.3); the agentic learning loop beyond single-shot derivation (ADR-0014's harness section is superseded by ADR-0021).
