## Goal

Add the music-video sub-mode to the existing render pipeline. Madmom (beats + downbeats) + librosa (sections + energy) analysis; tempo-aware beat-grid generation; section-to-media NL mapping (A-013, full version per D-031) passed verbatim to Stage 5; cuts snap to beats in music-video mode.

This is **M4**. After E-2.5 closes, the user can pick "music-video" mode and get cuts that align to the music's beats + a curation that respects their section-to-media spec.

## Scope

- `MusicAnalyzer` abstraction with `MadmomLibrosaAnalyzer` MVP implementation per [ADR-0012](../../docs/architecture/ADR-0012-music-alignment-strategy.md).
- Madmom integration: `RNNBeatProcessor` + `RNNDownBeatProcessor` for beat + downbeat timestamps.
- librosa integration: `librosa.segment.agglomerative` for sections + `librosa.feature.rms` for energy curve.
- `MusicAnalysis` Pydantic model (duration, BPM, BPM stability, beats_ms, downbeats_ms, sections, energy_curve, spectral_novelty).
- `CutGrid` generator with tempo-aware adjustment (slow/moderate/fast cut frequencies + section-boundary snapping within 200ms).
- Section-to-media NL spec field on the project's manifest.json (free-text); UI textarea on job creation form (when music-video mode is picked).
- Stage 5 prompt template variant for music-video mode that consumes `MusicAnalysis` + section-to-media NL spec; `ArcJudgment.section_mapping` field populated.
- Stage 6 plan compiler updated: in music-video mode, snap clip durations to `CutGrid.cut_points_ms`; in standard mode, use intended-duration-as-is.
- Stage 7 render updated: music-video mode = cuts snap to beat grid; standard mode unchanged.
- Music duration mismatch handling (`analyze_music_duration_mismatch` Tier-M tool) — orchestrator picks fade / loop / truncate per situation; applies in both modes.
- UI: mode picker (standard / music-video) on job-creation form is now functional; section-to-media NL textarea visible when music-video is picked.

## Out of scope

- Licensed-library music integration (v1 — D-018)
- Generated music (v2 — D-018)
