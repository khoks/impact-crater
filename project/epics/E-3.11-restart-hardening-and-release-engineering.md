## Goal

Land the non-feature work the restart plan (`docs/roadmap/LANDSCAPE-AND-PLAN-2026-10-24.md` §5, Phases 1–2) schedules before v1 formally opens: the model-lineup bump that makes any paid run possible, test CI on Linux as well as Windows (and the ADR-0004 `--admin` → `--auto` switch it triggers), a mid-job spend guard so no run can die the way the 2026-06-17 cold run did, local API hardening before any public URL, wheel packaging so an installed copy can route an LLM call, and the frontend dependency bump that clears 19 open advisories. It is hosted under I-3 rather than I-2 so that I-2 can close on the first real publish (D-057, to be recorded by S-2.13.2) while this hardening continues at `mvp-hardening` phase.
