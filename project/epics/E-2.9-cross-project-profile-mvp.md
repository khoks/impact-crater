## Scope

### Cross-project user profile (M8)

- Feedback log writer at `~/.impact-crater/profile/feedback_log.jsonl` per [ADR-0014](../../docs/architecture/ADR-0014-agent-harness-topology.md). Hooks into:
  - Approve clicks (after preview) — `event_type: approve`
  - Refine clicks — `event_type: refine`
  - Second-guess decisions per [ADR-0011](../../docs/architecture/ADR-0011-curation-engine-algorithm.md) — `second_guess_accepted` / `_rejected` / `_modified`
  - Refinement outcomes — `refinement_succeeded` / `refinement_failed`
  - Pre-filter / effort-level overrides — `pre_filter_overridden` / `effort_level_overridden`
  - Publish outcomes — `publish_succeeded` / `publish_failed`
  - Cancellations — `job_cancelled`
- Profile schema persisted at `~/.impact-crater/profile/profile.json` per [ADR-0014](../../docs/architecture/ADR-0014-agent-harness-topology.md): `StylePreferences` + `OrchestratorPriors` + `NarrativePatterns`.
- **Deterministic frequency-based derivation at MVP**: counts + averages over feedback events. No LLM-driven derivation at MVP — that's post-launch. The schema is the same, just populated by deterministic aggregation.
- Profile reader integrated at the six call sites per [ADR-0014](../../docs/architecture/ADR-0014-agent-harness-topology.md): job creation suggestions; brief parsing in-context priors; Stage 4 quality floor override; Stage 5 narrative-arc patterns; Stage 6 second-guess threshold; Stage 9 refinement strategy bias.
- Job-creation UI: when profile is non-empty, show "Based on your past trips, you usually want ~X-second videos with Y-tempo music; pre-fill these?" with accept / modify / ignore.
- Settings panel: profile reset button ("forget what you've learned about me") with confirmation dialog; resets feedback_log.jsonl + profile.json to empty.

### MVP polish (M9 build half)

- Bug fixes from M0..M8 surfacing during integration testing.
- Edge cases: source media path moves (content-hash fallback search); HEIC + RAW formats verified end-to-end; mixed 16:9 / 9:16 sources; very-slow / very-fast music tempos; empty person library; full person library at the cap.
- Documentation: README install walkthrough verified by a fresh-eyes reader; first-time-setup wizard copy reviewed for clarity.
- Cross-OS sanity: Windows 11 + macOS + Linux fresh-install paths re-verified.

### D-014 success-criterion validation (M9 validation half)

- The user (Rahul) runs a real 1000-photo + 50-video job from one of his own trips.
- Validate: 2–5 hour ceiling holds; the result is publish-ready; the user clicks Approve and Publish to a real YouTube account.
- Pre-flight criteria checklist from MVP.md walked through and ticked.
- Any blocking regressions trigger a hot-fix sub-task (and an extension to E-2.9 calendar time, but not scope).
