## Goal

Ollama runtime with the ≤32B cap enforced at model-load; the N-002 cost/capacity-aware router replaces the static routing dict; N-011 privacy-sensitive routing becomes functional. The restart plan (`docs/roadmap/LANDSCAPE-AND-PLAN-2026-10-24.md` §4.3 #19/#21, §5 Phase 3 item 2 and Phase 5) sequences the epic embedder-first, runtime-second: a hardware probe and the real local image embedder (ADR-0018, which brings torch) land in Phase 3 as quality work, the privacy-honesty minimum lands in Phase 2 without any local model, and the Ollama runtime, the operation-aware router and functional privacy routing follow in Phase 5. Exit per the plan: a full job runs Stage 2/3 on the owner's GPU within 2× remote wall-clock and $0 remote spend for those ops; the privacy matrix is enforced; MVP constraint #13 becomes true.

## Scope

- S-3.1.4 — privacy honesty minimum: explicit strip-EXIF at the rendition point, never send originals, truthful "What we send to the AI" copy (Phase 2 item 7)

- S-2.10.8 — local CLIP/SigLIP image embedder behind the ADR-0008 runtime slot; `build_image_embedder` gets its first caller; ADR-0018 → accepted (Phase 3 item 2)
- S-3.1.1 — Ollama runtime + ≤32B cap + hardware-tier mapping; the hardware-tier ADR is written here with real probe data (Phase 5)
- S-3.1.2 — N-002 operation-aware router (cost/capacity resolver) + per-op override UX + degraded mode (Phase 5)
- S-3.1.3 — N-011 privacy routing functional + the full three-toggle per-project matrix, `privacy_class` populated (Phase 5); supersedes S-2.6.4

- A local Tier-L judge: the plan keeps the judge remote by policy.
- Privacy copy and EXIF guarantees that need no local model are S-3.1.4 and ship in Phase 2, not with the runtime.
