## Goal

The first commit of actual application code. Stand up the empty-but-bootable shell: a pip-installable Python package that ships a `impact-crater` CLI; a FastAPI process that serves a built React static-asset bundle and an `/api/...` surface; a first-time-setup wizard that collects API keys + dual-cap spend caps + generates the Fernet key; and the SQLite schema initialization on first run.

This is **M0**. After E-2.1 closes, the empty app boots cleanly on a fresh install.

## Scope

- Python package `impact_crater` with the directory layout proposed in [ADR-0005](../../docs/architecture/ADR-0005-process-topology-language-stack.md): `backend/`, `frontend/`, `prompts/`, `config/`, `scripts/`.
- `pyproject.toml` with the MVP-baseline deps (locked at first task: `fastapi`, `uvicorn`, `pydantic`, `aiosqlite`, `aiofiles`, `cryptography` for Fernet, `httpx`).
- Console-script entry point: `impact-crater = impact_crater.cli:main`. `impact-crater` starts the FastAPI server on `localhost` and opens the user's default browser.
- FastAPI app skeleton with health check + `/api/setup/...` endpoints + static-asset serving for `frontend/dist/`.
- React app skeleton (Vite + TypeScript) with the first-time-setup wizard as its initial route.
- First-time-setup wizard collects: Anthropic API key, Google API key, total daily spend cap (≥$1, mandatory), per-provider caps (optional), `IMPACT_CRATER_HOME` override (optional).
- Fernet key generation at `~/.impact-crater/db/.fernet-key` (0600 perms on Unix; equivalent ACL on Windows).
- SQLite schema initialization (the tables defined in [ADR-0006](../../docs/architecture/ADR-0006-storage-layout.md) + [ADR-0013](../../docs/architecture/ADR-0013-connector-layer.md) + [ADR-0015](../../docs/architecture/ADR-0015-resource-accounting.md)) via Alembic.
- Cross-platform testing: Windows + macOS + Linux fresh-install paths.
