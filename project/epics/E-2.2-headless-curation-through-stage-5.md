## Goal

The biggest single MVP epic. Stand up the entire LLM stack (`LLMClient` protocol + Anthropic + Google providers + `LLMRouter` + telemetry + cache) plus the curation pipeline through Stage 5 (the N-001 narrative-arc judgment). At the end, feeding a test set + brief + target_duration via API produces a structured `ArcJudgment` JSON back. **No UI yet.**

This is **M1**, the vertical-slice early validation that the entire stack works end-to-end before any UI investment.

## Scope

- `LLMClient` Python `Protocol` per [ADR-0007](../../docs/architecture/ADR-0007-remote-llm-abstraction.md) with all typed async methods.
- `AnthropicLLMClient` implementation against the `anthropic` SDK; auth via `ANTHROPIC_API_KEY` from SQLite settings.
- `GoogleLLMClient` implementation against the `google-generativeai` SDK; auth via `GOOGLE_API_KEY`.
- `LLMRouter` that loads `config/llm-routing.yaml` (per [ADR-0009](../../docs/architecture/ADR-0009-cost-tiered-model-lineup.md)) and resolves per-operation routing.
- Per-operation prompt templates in `prompts/{operation}/{provider}_{model}.jinja2`; prompt_version = sha256 of template content.
- Read-through cache against the `cache_index` table per [ADR-0006](../../docs/architecture/ADR-0006-storage-layout.md).
- `LLMCallEvent` telemetry emission per call (per [ADR-0015](../../docs/architecture/ADR-0015-resource-accounting.md)) → `~/.impact-crater/telemetry.jsonl`.
- Worker pool per [ADR-0010](../../docs/architecture/ADR-0010-media-pipeline-framework.md) with `cpu` / `ffmpeg` / `network` worker classes.
- Pipeline Stage 1: media ingest (Pillow + pillow-heif + rawpy + ffmpeg-python), content-hash, scene segmentation (PySceneDetect), thumbnails.
- Pipeline Stage 2: bulk per-asset ops (`embed_image`, `caption_image`, `score_image`).
- Pipeline Stage 3: rich metadata extraction (`extract_metadata_image` with the D-009 schema). Person-library integration deferred to E-2.6.
- Pipeline Stage 4: deterministic pre-filter with floor + ceiling math from [ADR-0011](../../docs/architecture/ADR-0011-curation-engine-algorithm.md).
- Pipeline Stage 5: `judge_narrative_arc` Tier-L Opus call producing structured `ArcJudgment`.
- API endpoint `POST /api/jobs/headless` that accepts {media_paths, brief, target_duration, mode} and returns the `ArcJudgment` JSON for testing without UI.
- Pre-job quota check per [ADR-0015](../../docs/architecture/ADR-0015-resource-accounting.md) dual-cap model.
