## Goal

Wrap the headless pipeline (E-2.2 + E-2.3) in a usable React UI. User can drag media in, type a brief, pick effort level, see in-job progress + cost live spend, and get a preview Story Video. Approve / Refine UI buttons present (Approve does nothing yet — no connector lands until M7; Refine deferred to M6). **No YouTube publish yet.**

This is **M3**. After E-2.4 closes, a non-Engineer could (in principle) use the app on their own laptop and get a Story Video preview without touching the API.

## Scope

- React + TypeScript + Vite frontend, served as static assets from FastAPI per [ADR-0005](../../docs/architecture/ADR-0005-process-topology-language-stack.md).
- Project list / dashboard view (after first-time-setup wizard).
- New project creation flow: name + brief textarea + media drag-drop or folder pick.
- Effort-level UX with cost preview per [D-013](../../docs/decisions/DECISIONS_LOG.md): pre-canned L1 / L2 / L3 + agentic max-permissible recommendation surface; "this job will cost ~$X-Y; today's remaining budget $Z" pre-job preview.
- Brief input with optional fields: target_duration slider, mode picker (standard / music-video; music-video disabled at M3 since M4 lands the music-video logic), audio file upload.
- Job submission triggers the pipeline; in-job progress streamed via FastAPI websocket per [ADR-0005](../../docs/architecture/ADR-0005-process-topology-language-stack.md).
- Live spend display (per-tier breakdown, running total) per [ADR-0015](../../docs/architecture/ADR-0015-resource-accounting.md).
- Stage-based progress UI (Stage 1 ingest / Stage 2 bulk ops / ... / Stage 7 render) with per-stage `OrchestratorTurnEvent` updates.
- Preview UI: video player + Approve (primary) / Refine this result (secondary) buttons per [D-022](../../docs/decisions/DECISIONS_LOG.md). Approve placeholder for M3 (no connector); Refine disabled for M3 (lands in M6).
- Settings panel: API keys + spend caps (editable post-setup-wizard) + privacy panel placeholder (lands in M5).
- Project detail view with snapshot history (just the latest render at M3; multi-snapshot timeline lands in M6).
