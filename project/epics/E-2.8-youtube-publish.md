## Goal

Implement the `YouTubeConnector` end-to-end: OAuth via local-loopback callback; resumable `videos.insert` upload with 256 MB chunks; publish UI with visibility selector defaulting to public; audit-log writer. After E-2.8 closes, **the full MVP loop is closed end-to-end**: drop photos → curate → preview → approve → published video URL.

This is **M7**.

## Scope

- `Connector` Python protocol per [ADR-0013](../../docs/architecture/ADR-0013-connector-layer.md).
- `YouTubeConnector` MVP implementation: `google-auth-oauthlib` for OAuth + `google-api-python-client` for the YouTube Data API v3 calls.
- OAuth flow: local-loopback redirect (`http://localhost:<random_port>/oauth-callback`); user's browser opens for the OAuth dance; FastAPI completes the token exchange.
- Token storage in `connector_credentials` SQLite table; access_token + refresh_token Fernet-encrypted at rest with the key generated during E-2.1 first-time setup.
- Token refresh as a background task before every connector call; surface `ConnectorAuthError` on permanent failure.
- Resumable `videos.insert` upload protocol; 256 MB chunks; resume on network blip; progress streamed via FastAPI websocket.
- Publish UI: visibility selector (private / unlisted / public) defaulting to **public** per [D-032](../../docs/decisions/DECISIONS_LOG.md); title / description / tags inputs; Approve button reads "Publish as <visibility>" so the user sees the consequence one more time.
- Approve flow: connector.validate_artifact() → connector.upload() → audit-log entry appended to `~/.impact-crater/audit.jsonl` + mirrored in `audit` SQLite table per [ADR-0006](../../docs/architecture/ADR-0006-storage-layout.md).
- `user_approval_token` = opaque, in-session-bound; bound to the specific user click that approved this publish.
- API rejection handling: structured `ConnectorError` hierarchy per [ADR-0013](../../docs/architecture/ADR-0013-connector-layer.md) with YouTube error mapping table (400 / 401 / 403 / 5xx classes) → user-actionable messages surface via cost-transparency UI.
- Quota awareness: report YouTube Data API quota remaining after each call; surface in cost-transparency UI when approaching limit.
- Settings panel: connect / disconnect YouTube account flow.
- Audit-log viewer in the project detail view (read the last N publishes from the JSONL file or SQLite mirror).
