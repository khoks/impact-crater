## Goal

Make the D-042 "single-video quality mastery" gate measurable at $0 before any further heuristic or prompt change lands. Today no quality-regression harness exists: E-2.10 / E-2.12 acceptance has never been machine-checked, the only ad-hoc evaluator is the June scratch probe now kept as `docs/design/eval_headless_2026-06.py`, and no full-scale run has happened since the Vegas fix (PR #72). This epic promotes that idea into `scripts/eval_plan.py` with deterministic metrics computed from `plan.json` / `diagnostics.json` / `cast.json` on frozen fixtures, runs it as `pytest -m eval` in CI, exports the owner's decision-level feedback verdicts into a golden set the harness reports agreement with, and instruments cap violations so the D-053 repair-loop decision is made from numbers. The D-058 gate definition itself (two consecutive fresh renders of two real trips, publishable unchanged or after ≤ 2 refine passes, zero `incorrect` Stage 4/5 feedback, eval thresholds green) is written in Phase 2 item 1 of the restart plan and is what this harness enforces. Per A-029.

## Scope

- S-3.10.1 — `scripts/eval_plan.py` + thresholds + frozen SW-US / Zion fixtures + `pytest -m eval` (Phase 2 item 2)
