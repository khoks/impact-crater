## Description

As a user who posts trip videos to a Facebook Page, I want Approve & publish to offer Facebook alongside YouTube so the approved render reaches the Page without a manual upload. Delivered 2026-05-11 in PR #34 (commit 4a44c51) as `backend/impact_crater/connectors/facebook.py`, a month before this story was backfilled — with the same caveats as S-3.3.1: credentials are env vars (`IC_FACEBOOK_PAGE_ACCESS_TOKEN`, `IC_FACEBOOK_PAGE_ID`), publish defaults to dry-run, and no Facebook post, dry-run or live, has ever executed (the audit table is empty).

What shipped: a Graph API Page Videos upload. Personal-profile posting is deprecated, so only Pages are supported. Unlike Instagram the endpoint accepts inline multipart binary, so no `IC_PUBLIC_BASE_URL` is needed — the connector POSTs the MP4 directly to `graph.facebook.com/v21.0`. Visibility maps `public → published=true`, `unlisted → published=false + unpublished_content_type=DRAFT` (visible only in the Page's drafts), and `private` is rejected with a `ConnectorValidationError` suggesting `unlisted` or YouTube.

This story originally read "FacebookConnector + XConnector"; the X half was split out to S-3.3.4 on 2026-10-24 because only the Facebook connector exists.
