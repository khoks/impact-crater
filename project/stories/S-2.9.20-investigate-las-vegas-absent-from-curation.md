## Description

On the 1,663-asset SW-US-trip validation job, the brief named "zion, bryce,
horseshoe bend, grand canyon, and las vegas," but **no Las Vegas shots reached
the judge** — the judge itself noted "no Vegas candidates appeared in the
filtered set." Determine the cause:

- **(a)** No Vegas media in the input set (then it's expected — the brief over-
  specified), or
- **(b)** Vegas shots existed but were dropped at Stage-4 pre-filter (quality
  floor, location/time clustering cap, or relevance), i.e. a real curation gap.

If (b): decide whether the brief's explicit place list should *protect* named
locations from being fully filtered out (e.g. guarantee ≥1 candidate per named
place when media exists), or whether the location-cluster cap is too aggressive.

## Acceptance criteria

- [ ] Determine (a) vs (b) from the snapshot's Stage-3 metadata + Stage-4 filter log (location tags / dropped-with-reason for any Vegas-tagged shots).
- [ ] If (b), propose + implement the fix (e.g. brief-named-location protection) or file a follow-up; if (a), close as expected.

## Dependencies

- Data: the validation snapshot `b4b73c7b1fe044b7` (project-aa425a73c540) diagnostics + filter log.

## Activity log

- 2026-06-18 — filed (work-tracker) from the render evaluation (judge flagged Vegas missing).
- 2026-06-29 — **investigated; cause = (b), a real curation gap.** Of ~37 Nevada-area shots (Hoover Dam selfie specialness 0.72, Valley-of-Fire/Lake-Mead drive, the Henderson departure), **all were dropped at Stage 4 — 32 by `rank_below_target_size`** (the global top-K), 2 semantic-dup, 2 quality, 1 dedup. Root cause: `prefilter()` receives no brief, so a named destination has no protection from the global rank, and the trip genuinely had little Vegas-proper content (mostly transit) so those shots ranked below 621 others. The fix is exactly the "protect named locations" option in (b): **named-destination coverage reservation** — implemented as **S-2.10.5** (parse brief intent → reserve top 1–2 per named destination before the cut → require ≥1 judge beat or an honest "barely photographed" note). Closing this investigation; the fix is tracked under E-2.10 / ADR-0017 / D-053.
