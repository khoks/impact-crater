## Description

Rebuild `stage9_refine` into a bounded tool-use agent (ADR-0014) that interprets
arbitrary NL refinement requests, reasons over the analysis already computed, and
performs more analysis only when needed — then re-renders a child snapshot. Each
tool is a thin wrapper over the shared abstractions so an initial render and a
refined re-render run identical Stage-4/5/6 code.

## Acceptance criteria

- [ ] `/refine` loads the full context for a snapshot (brief, candidate set,
  media, music analysis, prior plan + directive) — not just the selected clips.
- [ ] Tools: `inspect_candidates`, `reserve_media`/`reserve_destination`,
  `adjust_durations` (→ PlanDirective), `edit_narrative` (re-judge),
  `reanalyze_media` (re-run Stage 3 on refs with new questions), `finalize`,
  `explain`/`ask_user` — each mapping to a pipeline entry point.
- [ ] Pure pacing edits re-run Stage 6 only (no re-judge); force-include re-runs
  Stage 4 through a `ReservationSet(source='refinement')` then re-judge; content
  edits re-judge.
- [ ] Bounded turns; produces a child snapshot (`parent_snapshot_id`) with a new
  `render.mp4`; endpoint returns the new snapshot id. Fail-soft with an
  explanation when a request can't be honoured.
- [ ] The four example requests work end-to-end (insert-destination, don't-drop-X,
  beginning-clips-longer, tempo-aware pacing).
