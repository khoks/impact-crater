## Description

Wire music-video mode through the existing Stage 5 / 6 / 7 pipeline:

- Stage 5: a music-video prompt template variant that consumes `MusicAnalysis` (beats/sections/energy) + the user's section-to-media NL spec verbatim → `ArcJudgment.section_mapping` populated.
- Stage 6: when mode=music_video, snap clip boundaries to `CutGrid.cut_points_ms` instead of the linear-scaling fallback.
- Stage 7: render path unchanged for cuts (the plan now carries snapped durations); audio-mix path unchanged.
- `MusicSpec` extended with optional pre-computed `MusicAnalysis` so callers can pass it through the runner.
