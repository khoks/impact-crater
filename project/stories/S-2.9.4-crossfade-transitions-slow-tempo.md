## Description

As a viewer of a slow-tempo scored video, I want gentle crossfades between clips instead of hard cuts, so the pacing matches the music's mood — per ADR-0011 §Stage 6 ("cross-fades on slow-tempo music; quick cuts on high-energy sections") and ADR-0012's beat-grid adjustment rules.

Observed 2026-06-11: `RenderClip.transition_in` supports `"crossfade"` in the model but Stage 6 always emits `"cut"` and Stage 7's concat-demuxer pipeline cannot express overlapping transitions (would need an xfade filter graph). Hard cuts are the ADR-conformant default for fast tempos (Gimme Shelter test was 117 BPM), so this is polish, not a bug — out of MVP per the MVP gate, filed at v1.

## Acceptance criteria

- [ ] Stage 6 sets `transition_in: crossfade` when tempo/section rules say so (slow tempo per ADR-0012)
- [ ] Stage 7 renders crossfades (xfade-based concat path) without breaking the cut-only fast path
- [ ] Beat-snap boundary semantics from D-041 preserved (crossfade midpoints land on cuts)
