## Description

Build the shared `PlanDirective` model (ADR-0019) and refactor Stage 6 to consume
it, replacing the hard-coded duration constants with directive fields whose
defaults reproduce today's behaviour exactly. This is the foundation the
positional/tempo levers (S-2.12.2) and the refinement layer (S-2.12.3) both build
on.

## Acceptance criteria

- [ ] `plan_directive.py`: `PlanDirective` + sub-models (`DurationBands`,
  `PositionalRule`, `TempoBand`/`TempoProfile`, `SoftAlignSpec`), `DEFAULT_DIRECTIVE`
  (no-op), `merge_directive(base, patch)`, `build_directive_from_music(...)`.
- [ ] `compile_plan(directive=None)` defaults to `DEFAULT_DIRECTIVE`; module
  constants become directive-field defaults; `_clip_band`/`_scale_to_target`/
  `_cap_per_location` read the directive; applied in the fixed order
  bands→positional→tempo→scale→soft-align (standard mode only).
- [ ] `RenderPlan.directive` persisted on plan.json (`schema_version` bump);
  `load_plan` tolerates old plans (default directive).
- [ ] Music-video path unchanged.
- [ ] Regression: existing `test_stage6_plan.py` byte-identical with no directive.
