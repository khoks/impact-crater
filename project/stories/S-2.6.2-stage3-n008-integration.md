## Description

Per ADR-0010 § N-008 + ADR-0007. When the person library is non-empty, Stage 3's `extract_metadata_image` call gets the analyzed photo *plus* the reference collage as a second image input. The schema gains `recognized_persons: list[{person_id, display_name, confidence, bbox_in_photo}]`. Confidence band:
- ≥0.85 → used directly downstream
- 0.5–0.85 → surfaced to user (M5 stretch; M5 baseline = drop)
- <0.5 → discarded

Cache key gains `library_version_hash` so adding/removing a person invalidates only the relevant cached extractions.
