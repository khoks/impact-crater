## Description

Per ADR-0015 + D-022:

- Job-in-progress view: WS-driven 7-stage progress bar + live spend rollup + per-stage activity log.
- Preview view: HTML5 `<video>` player serving the rendered MP4 over a static-file route the backend exposes for snapshot artifacts.
- Twin Approve / Refine buttons (per D-022). Approve = "Publish lands at M7" disabled-with-tooltip. Refine = "Refine lands at M6" disabled-with-tooltip.

## Acceptance criteria

- [ ] `frontend/src/routes/JobInProgress.tsx` — opens WS to `/api/ws/jobs/:job_id`; renders stage 1-7 progress with checkmarks; per-stage timestamps
- [ ] Live spend panel updates per `llm_call` event with running totals by tier
- [ ] On `job_completed` → routes to `/jobs/:job_id/preview`
- [ ] On `job_failed` → renders the failure detail + a "Back to Dashboard" button
- [ ] `frontend/src/routes/JobPreview.tsx` — `<video>` player of `/api/snapshots/{snapshot_id}/render.mp4`
- [ ] Backend: `GET /api/snapshots/{snapshot_id}/render.mp4` static-serves the file from the snapshot directory; 404 for unknown ids
- [ ] Approve / Refine placeholder buttons with tooltips
- [ ] `frontend/src/__tests__/JobInProgress.test.tsx` — mocked WS event sequence drives the UI through to the preview route
- [ ] `frontend/src/__tests__/JobPreview.test.tsx` — video src URL renders correctly
