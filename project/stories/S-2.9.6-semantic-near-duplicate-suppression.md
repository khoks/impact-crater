## Description

As a viewer, I never want to see two retakes of the same pose in one video. pHash (Hamming ≤ 5) only catches near-identical pixels; a retake from a slightly different angle survives today. Stage 2 already computes and caches an embedding per asset that nothing consumes — Stage 4 should cluster by embedding similarity (cosine, time-windowed), keep the best shot per cluster by the existing combined score, and drop the rest with filter-log reasons. Full design in A-017.
