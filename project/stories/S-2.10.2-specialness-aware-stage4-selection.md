## Description

As a user, I want the curator to actually use the "specialness" rating it pays a Tier-M model to compute, so once-in-a-trip moments aren't discarded in favour of bland-but-sharp frames.

## Acceptance criteria

- [x] `_combined_score` is 4-term `(0.25 quality, 0.40 narrative, 0.20 specialness, 0.15 diversity)`; weights overridable via `PreFilterOverrides`.
- [x] A high-specialness shot (≥0.75) survives the hard quality floor (logged `specialness_rescue`).
- [x] Dedup, semantic best-of-burst, and location-cap tie-breaks are specialness-aware (the most special member of a burst is kept).
- [x] Deterministic: stable secondary tie-break key; tests assert reproducible output.
