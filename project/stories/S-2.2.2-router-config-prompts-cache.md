## Description

Per ADR-0007 + ADR-0009 — `LLMRouter` reads `config/llm-routing.yaml`, resolves each operation to `(provider, model)`, and dispatches the call through the right `LLMClient`. Prompt templates live in `prompts/{operation}/{provider}_{model}.jinja2` with `prompt_version = sha256(template)`. Read-through cache against the SQLite `cache_index` table (per ADR-0006); cache key includes content_hash + provider + model + model_version + operation + prompt_version + params_canonical (per N-007).
