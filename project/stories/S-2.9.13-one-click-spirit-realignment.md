## Description

A documentation + UI audit (13-agent review, adversarially verified) found the
product is positioned as an "AI-driven photo/video **curator**" / multi-stage
"orchestrator" pipeline rather than its true spirit: a **dead-simple 1-click
media-to-video creator** — dump media, describe the video(s)/platform(s) in your
own words, click submit, done; the AI does everything behind that one click
(prepare, plan, create, publish-after-approval). The mis-framing is why a
NotebookLM deck generated from `docs/OVERVIEW.md` kept calling the app an
orchestrator. `RAW_VISION.md` confirms the 1-click spirit is original intent and
scopes the agentic harness as internal — the drift is in derived docs + UI
emphasis, not intent.

Owner refinements (override "hide complexity" instinct): **keep** the mandatory
Effort & cost preview (real money — transparency is a feature) and **keep** the
live per-phase execution view (it shows the app's prowess and explains elapsed
time) — but make the live view **beautiful, engaging, and collapsible**, and
strip only jargon-as-identity leaks (literal "orchestrator", "narrative judge",
bare model/tier IDs as user-facing identity).

## Acceptance criteria

- [x] All docs lead with the 1-click identity; "orchestrator/pipeline/stage" framed as internal: `OVERVIEW.md`, `README.md`, `CLAUDE.md` (Mission), `ROADMAP.md`, `MVP.md`, `GROOMED_FEATURES.md`, `NOVEL_IDEAS.md`, `RECOMMENDED_ADDITIONS.md`, `ARCHITECTURE.md`. `RAW_VISION.md` left untouched (verbatim benchmark).
- [x] GitHub Pages (built from `OVERVIEW.md`) reflects the new framing.
- [x] App UI leads with the 1-click identity: Dashboard hero, New Project CTA ("Create a video"), Effort & cost copy, Setup welcome.
- [x] Jargon leaks removed from user copy: JobPreview "orchestrator" → "Impact Crater"; NewProject "narrative judge" → "the AI"; JobInProgress tier labels de-jargoned.
- [x] Mandatory Effort & cost preview kept (cost transparency) — reworded only ("One last step — effort & cost" / "Create my video"); not auto-skipped/hidden.
- [x] Live in-progress execution view rebuilt: current-activity banner, gradient timeline with animated nodes + per-phase blurbs, friendly "what the AI is doing" phase names, live spend, and a "Hide details / Show details" collapse toggle. Still surfaces all phases (prowess).
- [x] Frontend tests updated + green (38/38); tsc + vite build clean.
