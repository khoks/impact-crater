## Description

As a user, I want near-identical shots to actually be detected as similar and varied shots to register as diverse — which the current embedding can't reliably do, because Gemini has no native image embedding so Stage 2 captions the image then embeds the *caption text*. Two different moments with similar captions collide; six near-identical Grand Canyon shots only differed enough in caption to survive dedup. A real visual embedder is the root-cause fix for the variety/dedup weakness (F2/F3).

## Acceptance criteria

- [ ] Stage 2 uses a local image embedder (open_clip ViT-L/14 or SigLIP) producing true visual vectors, behind the ADR-0008 runtime slot, with the gemini caption-embed kept as a low-resource/cloud fallback.
- [ ] Semantic dedup + diversity thresholds re-tuned for the new embedding space (the 0.93 cosine is calibrated for caption-text vectors and will change).
- [ ] A fixture of 6 near-identical Grand Canyon shots collapses under the new embedder where it currently survives.
