## Notes

Root cause of the hang: `html-to-image` `toPng(document.body, {cacheBust:true})` re-fetched every resource (including a stalled `render.mp4` `<video>`) with no internal timeout, and `onSubmit` awaited it before POSTing — so a single stalled fetch blocked submission forever. Discovered live while submitting the analysis feedback for snapshot b4b73c7b1fe044b7 (worked around by posting via the same `/api/feedback` endpoint). Frontend changes need a `npm run build` to take effect in the served bundle.
