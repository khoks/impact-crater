## Description

Per ADR-0010 — asyncio task pool with three worker classes (`cpu`, `ffmpeg`, `network`) and per-class concurrency limits. `JobCancelled` exception propagates through tool calls. Pipeline stages submit work via `pool.submit(class, callable, *args)`. Used by Stages 1-7 to parallelize per-asset operations within a job.

## Acceptance criteria

- [ ] `backend/impact_crater/workers/__init__.py` + `workers/pool.py` — WorkerPool class with submit + cancel
- [ ] Per-class concurrency limits configurable via `IC_WORKER_*` env vars; sensible defaults (cpu=os.cpu_count(), ffmpeg=2, network=8)
- [ ] `JobCancelled` exception + propagation
- [ ] `tests/test_worker_pool.py` — concurrency + cancellation + per-class isolation
