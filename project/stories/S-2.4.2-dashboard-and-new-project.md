## Description

Replace the M0 stub Dashboard with the real project list + "New Project" button. New-project flow: name + brief textarea + media folder picker + audio file picker.

Browsers don't expose absolute filesystem paths in drag-drop, so the UI uses a folder-path text input as the authoritative source (with `<input type="file" webkitdirectory>` for visual feedback that surfaces the file count). The path is sent to `GET /api/folder/scan` for server-side scanning.

## Acceptance criteria

- [ ] New `frontend/src/api/projects.ts` + `api/jobs.ts` + `api/folder.ts` thin fetch wrappers
- [ ] Dashboard route lists projects (just placeholder for M3; no project-CRUD until M4 — display "No projects yet" with the New button)
- [ ] `frontend/src/routes/NewProject.tsx` — multi-step or single-form flow:
  1. Name + brief textarea
  2. Media folder path (with optional file picker for visual file count)
  3. Audio file path
  4. Target duration slider (5–600s)
- [ ] Folder scan triggers on path entry; shows photo + video counts + total size
- [ ] Form validation: name + brief + folder + audio + duration all required before "Continue"
- [ ] Continue button navigates to the effort-level + cost-preview surface (S-2.4.3)
- [ ] `frontend/src/__tests__/NewProject.test.tsx` — folder-scan integration, validation, navigation
