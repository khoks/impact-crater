## Description

Per ADR-0010 + N-008. The `persons` + `person_face_photos` SQLite tables already exist (added in M0's `001_init.sql`). Add the CRUD API + the reference-collage builder that tiles labeled face crops into a single PNG cached at `~/.impact-crater/cache/face-library/{library_version_hash}.png`.

The collage is the load-bearing piece: Stage 3 sends it as a second image input to the vision LLM and asks "which of these labeled people appear in the photo I'm analyzing?".

## Acceptance criteria

- [x] `backend/impact_crater/api/persons.py` — POST/GET/DELETE on persons + add face photo with bbox crop
- [x] `backend/impact_crater/media/collage.py` — `build_reference_collage(persons) → (Path, library_version_hash)` tiles up to 5 face photos per person with name labels
- [x] Library version hash = sha256(sorted(person_ids + photo_hashes)) per ADR-0010 § N-008
- [x] Collage cached at `~/.impact-crater/cache/face-library/{hash}.png`; regenerated only on hash change
- [x] `tests/test_persons_api.py` + `tests/test_collage.py` — CRUD round-trip + collage build with synthetic photos
