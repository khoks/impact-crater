## Description

As a user with thousands of full-resolution photos, I want analysis to run on cheap renditions instead of 9–12 MB originals, so jobs are faster and cheaper with no quality loss at VLM input resolutions.

Stage 1 already builds 256/1024px thumbnails and scenedetect picks 3 representative frames per video scene — but Stage 2/3 read FULL-SIZE source bytes per LLM call (Anthropic's client downscales internally; Gemini uploads the originals). And a long single-take video yields one scene = 3 analyzed frames, under-sampling exactly the footage the user worries about. Full design in A-016.
