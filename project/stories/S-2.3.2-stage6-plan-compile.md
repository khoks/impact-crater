## Description

Per ADR-0011 Stage 6 (without orchestrator second-guess — that lands in M6) — walk the `ArcJudgment.selected_items`, compute final clip durations, insert simple cuts (no music-video beat-snap; music-video lands in M4), validate against target_duration, run smart-crop where needed, and persist as `snapshots/{snapshot_id}/plan.json` per ADR-0006.

Standard mode only at M2; music-video mode = `NotImplementedError("M4")` so attempts to use it fail loudly rather than silently.

## Acceptance criteria

- [ ] `backend/impact_crater/pipeline/stage6_plan.py` — `compile_plan(arc_judgment, ingest_records, *, target_duration, mode, audio) → RenderPlan`
- [ ] `RenderPlan` Pydantic model with ordered `clips` (each: `source_path`, `media_type`, `start_seconds`, `end_seconds`, `intended_duration_ms`, `aspect_ratio_action`, `transition`)
- [ ] Smart-crop on photos via `smartcrop.py` to fit 16:9; pad-or-letterbox 9:16 sources
- [ ] Validate sum of clip durations is within ±10% of target_duration; if not, scale clip durations linearly to fit
- [ ] Snapshot creation: `~/.impact-crater/projects/{project_id}/snapshots/{snapshot_id}/plan.json` written + DB row inserted
- [ ] `tests/test_stage6_plan.py` — clip-duration math, smart-crop fallback, plan.json round-trip, snapshot DB row
