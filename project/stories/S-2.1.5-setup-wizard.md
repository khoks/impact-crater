## Description

Implement the 6-step first-time-setup wizard end-to-end: React UI per the user-accepted field set; `/api/setup/...` endpoints (status, save-key, test-key, save-caps, complete); Fernet key generation and API-key encryption at "Finish"; settings persisted to SQLite; routing flips to Dashboard after Finish; subsequent loads skip the wizard.

## Acceptance criteria

- [ ] Step 1 Welcome: explainer + "Get started"
- [ ] Step 2 Anthropic API key: input + "Test" button → POST `/api/setup/test-key` with `{provider: "anthropic", key}` → returns success/failure
- [ ] Step 3 Google API key: same pattern
- [ ] Step 4 Daily spend cap: total cap (required, ≥$1) + per-provider caps (optional, ≤ total); zod validation
- [ ] Step 5 Storage location: `IMPACT_CRATER_HOME` override (optional) + privacy-toggle defaults preview (read-only)
- [ ] Step 6 Confirm: summary + "Finish" → POST `/api/setup/complete` with all collected values
- [ ] On Finish: API encrypts API keys with Fernet; persists to settings table; sets `setup_complete = "true"`; returns success → frontend navigates to `/dashboard`
- [ ] `/api/setup/status` returns `{setup_complete: bool}`; the React app reads this on first paint and routes accordingly
- [ ] `tests/test_api_setup.py` covers: status before completion, status after completion, save-key encryption round-trip, test-key endpoint shape, complete validation
- [ ] `frontend/src/__tests__/Setup.test.tsx` covers: step navigation, validation errors surfacing, finish-button-only-enabled-when-complete
