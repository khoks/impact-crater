## Description

Implement the 6-step first-time-setup wizard end-to-end: React UI per the user-accepted field set; `/api/setup/...` endpoints (status, save-key, test-key, save-caps, complete); Fernet key generation and API-key encryption at "Finish"; settings persisted to SQLite; routing flips to Dashboard after Finish; subsequent loads skip the wizard.

## Acceptance criteria

- [x] Step 1 Welcome: explainer + "Next"
- [x] Step 2 Anthropic API key: password input + "Test" button → POST `/api/setup/test-key`; success/failure surfaced inline
- [x] Step 3 Google API key: same pattern
- [x] Step 4 Daily spend cap: total cap (required, ≥$1, ≤$100k) + per-provider Anthropic + Google caps (optional, ≤ total); zod validation with `superRefine` enforcing the per-provider ≤ total rule
- [x] Step 5 Storage location: `IMPACT_CRATER_HOME` override (optional, informational) + privacy-toggle defaults preview (read-only)
- [x] Step 6 Confirm: summary with masked API keys + "Finish" button → POST `/api/setup/complete`
- [x] On Finish: API encrypts API keys with Fernet (per ADR-0013) + persists to settings table + marks setup_complete; React updates Zustand status + navigates to `/dashboard`
- [x] `/api/setup/status` returns `{setup_complete: bool}`; the React App.tsx reads this on first paint and routes accordingly (S-2.1.4)
- [x] `tests/test_api_setup.py` covers: status before/after completion; test-key empty rejection (422 via Pydantic min_length); test-key unknown provider (422); test-key valid happy path; complete with full payload encrypts keys + persists caps + marks done; complete with per-provider > total returns 422; complete with total < $1 returns 422; complete with omitted per-provider caps stores empty strings; complete twice returns 409
- [x] `frontend/src/__tests__/Setup.test.tsx` covers: starts on Step 1 with Back disabled; advances to Step 2; Next disabled until Anthropic key entered; Test button calls API + surfaces result
