## Description

Stand up the React app skeleton: Vite for build/dev, TypeScript strict mode, Tailwind for styling, react-router-dom for client-side routing (Setup ↔ Dashboard), Zustand for global state (current setup-complete flag, current project later). On first paint, the app calls `/api/setup/status` and routes to `/setup` or `/dashboard` accordingly. Vitest placeholder configured + green.
