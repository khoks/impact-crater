## Description

Per ADR-0010 + ADR-0012 — locate ffmpeg + ffprobe binaries via:
1. `IMPACT_CRATER_FFMPEG` / `IMPACT_CRATER_FFPROBE` env overrides
2. `shutil.which` (PATH lookup)
3. Standard winget install path on Windows (`$LOCALAPPDATA\Microsoft\WinGet\Packages\Gyan.FFmpeg_*\ffmpeg-*-full_build\bin\`)

Wrap subprocess invocation so render code never shells out raw. Audio probe via ffprobe for the music-ingest path (M4 brings full music analysis; M2 needs duration only).
