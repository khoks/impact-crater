## Description

Wire up the `impact-crater` CLI entry point that starts the FastAPI server on a free `localhost` port and opens the user's default browser. FastAPI app exposes `/api/health` and serves the built React frontend from `frontend/dist/` (or a "frontend not built" placeholder if dist doesn't exist).

## Acceptance criteria

- [x] `impact-crater` CLI command starts uvicorn + opens browser (with `--no-browser` opt-out)
- [x] Auto-port-pick: try 8765 first, fall back to OS-assigned free port; explicit `--port` errors if taken
- [x] `/api/health` returns `{"status": "ok", "version": "..."}`
- [x] Static-asset serving for `frontend/dist/` (dev) or `impact_crater/frontend_dist/` (packaged); helpful "not built" placeholder HTML if neither exists
- [x] SPA fallback so client-side routes (`/setup`, `/dashboard`) serve `index.html`
- [x] FastAPI lifespan runs migrations on startup (stubbed in S-2.1.2; real impl in S-2.1.3)
- [x] `tests/test_app.py` covers `/api/health`, `/api/setup/status`, `/api/projects`, `/`, `--version`, port auto-pick
