## Description

Per ADR-0011 + ADR-0015 — extend the headless API with a render endpoint that takes the M1 ArcJudgment + the user's audio + target_duration and returns the path to a rendered MP4. Aggregate `JobCostSummary` across the full Stages 1-7 run and persist to `snapshots/{snapshot_id}/cost_summary.json` per ADR-0015.

`POST /api/jobs/headless` (M1) becomes `POST /api/jobs/curate` for clarity; new `POST /api/jobs/render` accepts an existing snapshot or a fresh curation+render in one call.

## Acceptance criteria

- [ ] Extended `backend/impact_crater/api/jobs.py` — new `POST /api/jobs/render` endpoint
- [ ] Request: `{media_paths, brief, target_duration, audio_path, mode="standard", project_id?}`
- [ ] Response: `{snapshot_id, render_path, render_duration_ms, output_bytes, cost_summary}`
- [ ] `cost_summary.json` persisted alongside `render.mp4` in the snapshot dir
- [ ] 412 when keys not configured; 402 when quota denies; 422 on invalid body; 500 with structured detail when ffmpeg fails
- [ ] Music-video mode → 501 Not Implemented at M2
- [ ] `tests/test_api_render.py` — happy path with mocked router + real ffmpeg synthetic media; failure paths
- [ ] `tests/integration/test_full_render_pipeline.py` — full real-API run from ingest → render to MP4 (gated `--integration`)
