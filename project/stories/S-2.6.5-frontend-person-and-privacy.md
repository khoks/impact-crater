## Description

UI for both M5 features. Person library: list / add person / list face photos / mark primary / delete person. The face cropper UI is a v1 stretch — at MVP we accept a pre-cropped face image (drag-and-drop) and a bounding box can be optional (default: whole image).

Privacy panel in Settings: three toggles per ADR-0016 (strip_exif, strip_gps_only, blur_faces) with the interaction matrix explained inline. "What we send to LLM providers" surface explains what each posture does in plain English.
