## Description

Per ADR-0007 — define the `LLMClient` Python `Protocol` (PEP 544 structural typing) with typed async methods per operation, then implement two concrete providers: `AnthropicLLMClient` (against the official `anthropic` SDK) and `GoogleLLMClient` (against `google-genai`). Auth via the `settings` table (Fernet-decrypted at read time per ADR-0006/0013) with optional env-var fallback for tests.
