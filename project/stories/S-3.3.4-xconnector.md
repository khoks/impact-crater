## Description

As a user who also shares trip videos on X, I want Approve & publish to offer X alongside YouTube, Instagram and Facebook so the same approved render reaches X without a manual upload. Split out of S-3.3.2 ("FacebookConnector + XConnector") on 2026-10-24 because only the Facebook half was ever built. The restart plan lists this as "XConnector if still wanted" in Phase 4: X's API access and media-upload limits have shifted since the 2026-04 roadmap, so the owner confirms it is still wanted (and which API tier they hold) before any code lands.

## Acceptance criteria

- [ ] `backend/impact_crater/connectors/x.py` implements the ADR-0013 `Connector` protocol (`is_connected`, `validate_artifact`, `upload`) against the **official X API v2** only — chunked media upload (INIT → APPEND → FINALIZE, then STATUS polling for video processing) followed by `POST /2/tweets` with the returned `media_id`; no web-UI scraping (CLAUDE.md rule).
- [ ] Credentials via env vars first (`IC_X_*` for the OAuth user context the chosen tier requires), detected by `is_connected()` exactly as the Instagram / Facebook connectors do; the Settings Connect flow follows once S-3.3.5 has established the loopback-OAuth → `connector_credentials` pattern.
- [ ] `Platform` Literal, `LIVE_PUBLISH_PLATFORMS` and `get_connector()` in `connectors/base.py` / `connectors/__init__.py` include `"x"`; the dry-run wrapper applies by default (`IC_PUBLISH_DRY_RUN`), and a dry-run publish writes an audit row with platform `"x (dry-run)"`.
- [ ] `validate_artifact` enforces X's video constraints before upload (duration ≤ 140 s, size ≤ 512 MB, MP4 H.264 / AAC — re-verify against the current developer docs at build time) with a `ConnectorValidationError` naming the limit; X has no private / unlisted posts, so non-public visibility is rejected with a suggested alternative, mirroring S-3.3.1.
- [ ] Caption text is composed from the publish copy (S-3.3.7 when present, else title + brief excerpt) and truncated to the post length limit with the URL budget accounted for.
- [ ] Stub-transport tests in `tests/test_connectors_multi_platform.py` cover env detection, validation rejects, and the full chunked flow; the platform picker in `JobPreview.tsx` lists X when connected.
