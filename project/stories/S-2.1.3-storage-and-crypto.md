## Description

Lock the on-disk substrate: `~/.impact-crater/` paths (overridable via `IMPACT_CRATER_HOME` per ADR-0006); aiosqlite connection helpers; the hand-written migration runner with `001_init.sql` covering every table from ADR-0006 + ADR-0013 + ADR-0015 + ADR-0010 person library; Fernet key generation + encrypt/decrypt for token storage per ADR-0013.

## Acceptance criteria

- [x] `paths.py` resolves `~/.impact-crater/` (overridable via `IMPACT_CRATER_HOME` env var); creates the dir tree on first call; helpers for `db_dir`, `db_path`, `fernet_key_path`, `projects_dir`, `cache_dir`, `telemetry_path`, `audit_path`, `profile_dir`; cross-platform `harden_secret_file` (chmod 0600 on POSIX, no-op on Windows with note)
- [x] `db.py` aiosqlite connection helper with `connection()` async context manager applying the standard PRAGMAs (`foreign_keys ON`, `journal_mode WAL`, `synchronous NORMAL`)
- [x] `migrations.py` runner: tracks `schema_migrations(version PK, filename, applied_at)`; applies new files in `migrations_sql/` in order (filename pattern `{NNN}_{name}.sql`); idempotent
- [x] `001_init.sql` includes all 11 ADR-required tables: `schema_migrations`, `settings`, `projects`, `media`, `project_media`, `snapshots`, `audit`, `cache_index`, `connector_credentials`, `quota_state`, `persons`, `person_face_photos`. Indexes for the obvious query patterns.
- [x] `crypto.py`: `get_or_create_key()` generates the Fernet key on first use at `~/.impact-crater/db/.fernet-key` with `paths.harden_secret_file()`; `encrypt()` / `decrypt()` helpers; `FernetUnavailable` for corruption/wrong-key
- [x] `storage/settings.py`: `set_value(key, value, encrypted=False)` upserts; `get_value(key, default=None)` decrypts when needed; `is_setup_complete()` / `mark_setup_complete()` shortcuts; `KEY_*` registry for known keys
- [x] `tests/test_storage.py` + `tests/test_crypto.py` covering paths resolution, migration application + idempotency, settings round-trip (plain + encrypted), Fernet key generation/reuse/corruption/wrong-ciphertext
