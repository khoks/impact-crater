## Description

Lock the on-disk substrate: `~/.impact-crater/` paths (overridable via `IMPACT_CRATER_HOME` per ADR-0006); aiosqlite connection helpers; the hand-written migration runner with `001_init.sql` covering every table from ADR-0006 + ADR-0013 + ADR-0015 + ADR-0010 person library; Fernet key generation + encrypt/decrypt for token storage per ADR-0013.

## Acceptance criteria

- [ ] `paths.py` resolves `~/.impact-crater/` (overridable via `IMPACT_CRATER_HOME` env var); creates the dir tree on first call
- [ ] `db.py` aiosqlite connection helper with proper context-manager semantics
- [ ] `migrations.py` runner: tracks `schema_migrations` table; applies new files in `migrations_sql/` in order; idempotent
- [ ] `001_init.sql` includes: `schema_migrations`, `projects`, `media`, `project_media`, `snapshots`, `audit`, `settings`, `cache_index`, `connector_credentials`, `quota_state`, `persons`, `person_face_photos`
- [ ] `crypto.py`: Fernet key generation at `~/.impact-crater/db/.fernet-key` with 0600 perms (Unix) or equivalent ACL (Windows); encrypt/decrypt helpers
- [ ] `settings.py`: read/write the SQLite `settings` key-value table with optional Fernet encryption per key
- [ ] `tests/test_storage.py` + `tests/test_crypto.py` covering migration idempotency, settings round-trip, Fernet round-trip
