## Description

Per ADR-0012, deliver `MusicAnalyzer` abstraction. **Madmom (the ADR's first choice) is incompatible with Python 3.12** — last release 2024-01 predates 3.12 and the setup.py doesn't build under modern packaging. Per ADR-0012's escape hatch: ship a librosa-only implementation now, leave the abstraction so v1 can swap to BeatNet (which is torch-based and lands naturally with the ADR-0008 local-LLM work).

Outputs `MusicAnalysis` Pydantic model with duration / BPM / beats_ms / downbeats_ms (estimated from beats via downbeat heuristic) / sections / energy_curve. Generates `CutGrid` with tempo-aware adjustment + section-boundary snapping.

## Acceptance criteria

- [ ] `backend/impact_crater/media/music.py` — `MusicAnalyzer` Protocol + `LibrosaMusicAnalyzer` implementation
- [ ] `MusicAnalysis` + `Section` + `CutGrid` Pydantic models per ADR-0012 schema
- [ ] Beat tracking via `librosa.beat.beat_track`; sections via `librosa.segment.agglomerative`; energy via `librosa.feature.rms`
- [ ] Tempo-aware cut grid: <80 BPM → 8-beat cuts; 80-140 → 4-beat; >140 → 8-beat; section boundaries within 200ms snap
- [ ] `analyze(audio_path) → MusicAnalysis` runs in <30s for a 4-minute track
- [ ] `tests/test_music_analyzer.py` — synthetic WAV (multi-tempo + multi-section) round-trips through analyze + cut-grid math + tempo-aware adjustment
