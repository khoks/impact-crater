## Description

Per ADR-0012, deliver `MusicAnalyzer` abstraction. **Madmom (the ADR's first choice) is incompatible with Python 3.12** — last release 2024-01 predates 3.12 and the setup.py doesn't build under modern packaging. Per ADR-0012's escape hatch: ship a librosa-only implementation now, leave the abstraction so v1 can swap to BeatNet (which is torch-based and lands naturally with the ADR-0008 local-LLM work).

Outputs `MusicAnalysis` Pydantic model with duration / BPM / beats_ms / downbeats_ms (estimated from beats via downbeat heuristic) / sections / energy_curve. Generates `CutGrid` with tempo-aware adjustment + section-boundary snapping.
