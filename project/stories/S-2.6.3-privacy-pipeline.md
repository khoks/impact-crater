## Description

Per ADR-0016. Two pre-LLM image transforms with their own caches:

- **strip-EXIF / strip-GPS-only:** `piexif`-driven byte-level strip (ADR-0010 names pyexiv2 but piexif is the pure-python equivalent that builds on Python 3.12 without libexiv2 as a system dep). Cached at `~/.impact-crater/projects/{pid}/cache/stripped/{content_hash}.{ext}`.
- **face-blur:** mediapipe face-detection (chosen over dlib's `face-recognition` since dlib pulls a heavyweight C++ build chain; mediapipe ships pre-built wheels). Gaussian blur on detected boxes. Cached at `~/.impact-crater/projects/{pid}/cache/blurred/{content_hash}.jpg`.

Per-project privacy posture stored in `projects.privacy_settings_json`. The pipeline reads this when loading bytes for any LLM call.
