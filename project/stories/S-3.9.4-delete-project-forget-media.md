## Description

As a user, I want to delete a project and have the app forget the derived data it built from my media — database rows, LLM cache payloads, scene frames, thumbnails, feedback screenshots — so that the privacy promise in the public overview is one the code can honour. Today no such path exists: the only `@router.delete` routes are in `api/persons.py` (person and face-photo rows); nothing removes a project's rows, cache payloads, scene frames, thumbnails or feedback screenshots; the 92 GB cleanup has no code path; and because `api/media.py` globs thumbnails across projects by content hash, deleting one project's cache by hand can break another project's diagnostics (landscape §4.2 "Delete project / forget media", §4.3 #41). Built together with S-3.9.3, after the thumbnail lookup is content-addressed.

## Acceptance criteria

- [ ] `DELETE /api/projects/{id}` (+ a Dashboard action with confirmation) removes the project's `projects`, `project_media`, `snapshots` and job rows, its render/snapshot directories, its feedback rows and screenshots, and every scene frame, thumbnail and LLM-cache payload whose content hash is referenced by no other project; shared entries survive
- [ ] Published snapshots are never deleted: the request is refused (listing the audit rows) or the snapshot is kept with a tombstone, by explicit user choice
- [ ] Telemetry receives a tombstone event per deleted project (existing lines are never rewritten — append-only); the feedback JSONL gets a tombstone line too, closing the "mirror" divergence noted in S-2.13.3
- [ ] A "Forget media" variant keeps the project and brief but drops all its derived caches, for re-analysis after a model bump
- [ ] Tests: two projects sharing a content hash — deleting one keeps the shared thumbnail, frame and cache payload, deleting the other removes them; refusal on a published snapshot; feedback screenshots gone
- [ ] The 92 GB cleanup is performed through this path (dated live run in the activity log), and `docs/OVERVIEW.md`'s privacy text describes exactly what deletion removes and nothing more
