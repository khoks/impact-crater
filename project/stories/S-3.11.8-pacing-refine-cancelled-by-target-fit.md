## Description

As the owner refining a video, I want "slow the pacing" to make shots hold longer — and the app's reply to describe what really changed — so that a refine never claims the opposite of what it rendered. On 2026-11-03 (S-2.9.21, snapshot `9c16a02b8db94d15` → child `07bcb4d4114d4943`) the request "Slow the pacing a little — hold each shot a bit longer so the canyon views can breathe" produced a timing-only patch from the Stage 9 planner (Haiku 5.5): a global positional ×1.2 plus ×1.3 over the canyon section, `raises_band: false`. The reply said the clips were "re-timed to run longer". In the render, 12 of 13 photos got shorter (3.00 → 2.46 s, 2.58 → 2.46 s), the five canyon video clips grew ×1.24, and the total moved only 62.2 → 63.0 s.

**Root cause:** `stage6_plan.py` applies the positional rules, then `_scale_to_target` clamps every clip into its band (photos 1.5–3 s unless `raises_band`) and shrinks the whole timeline back within 10 % of the target — the S-2.12.2 contract ("total stays within target after scale"). At a fixed target duration, a uniform lengthening is cancelled; only fewer clips can make each one hold longer. The planner picks a lever that cannot deliver the request, and its interpretation text is written before the plan is compiled, so it cannot notice.

## Acceptance criteria

- [ ] Whole-timeline pace requests ("slower", "more breathing room", "faster", "punchier") change the clip count — the content path with a smaller / larger selection, or a directive field such as a target clip count — instead of a global positional multiplier; region-scoped requests ("slower opener") keep using positional rules
- [ ] The planner prompt states the fixed-duration trade-off and when `raises_band` is needed
- [ ] The refine reply is built from the compiled plan diff (mean photo / video hold before → after, clips added / removed, total length), not only from the planner's intent text
- [ ] A plan-diff check (S-3.10.1 harness) asserts that a "slower" refine raises the mean photo hold on the Zion fixture
