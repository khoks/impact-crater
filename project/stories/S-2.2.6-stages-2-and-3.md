## Description

Per ADR-0011 Stages 2 + 3:

- **Stage 2** (bulk per-asset ops): `embed_image` + `caption_image` + `score_image` (quality + narrative-relevance dimensions) running in parallel via the worker pool. Cached by content_hash + provider + model + model_version + operation. Brief-aware narrative-relevance scoring folds `brief_hash` into the cache key so changing the brief invalidates only narrative scores.
- **Stage 3** (rich metadata): `extract_metadata_image` + `extract_metadata_video_scene` producing the D-009 schema (people / location / mood / lighting / quality / activity / objects / clothing / pose / tags). Schema-validated structured output via Pydantic v2; rejects on validation error. Person-library integration deferred to M5.
