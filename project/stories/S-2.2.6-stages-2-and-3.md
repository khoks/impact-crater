## Description

Per ADR-0011 Stages 2 + 3:

- **Stage 2** (bulk per-asset ops): `embed_image` + `caption_image` + `score_image` (quality + narrative-relevance dimensions) running in parallel via the worker pool. Cached by content_hash + provider + model + model_version + operation.
- **Stage 3** (rich metadata): `extract_metadata_image` + `extract_metadata_video_scene` producing the D-009 schema (people / location / mood / lighting / quality / activity / objects / clothing / pose / tags). Schema-validated structured output via Anthropic's tool-use mode. Person-library integration deferred to M5.

## Acceptance criteria

- [ ] `backend/impact_crater/pipeline/stage2_bulk_ops.py` — runs all 3 op types in parallel via WorkerPool's `network` class
- [ ] `backend/impact_crater/pipeline/stage3_metadata.py` — issues per-asset metadata calls; validates returned JSON against the D-009 Pydantic schema; rejects + retries on schema mismatch
- [ ] `backend/impact_crater/pipeline/types.py` — D-009 metadata Pydantic models (RichMetadataPhoto, RichMetadataVideoScene)
- [ ] `tests/test_stage2_bulk_ops.py` + `tests/test_stage3_metadata.py` — unit + integration covered
