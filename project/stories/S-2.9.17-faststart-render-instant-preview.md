## Description

The Stage-7 ffmpeg mux writes the mp4 with the `moov` atom at the end (not
"faststart"), so an inline `<video>` without autoplay (e.g. the new
`SnapshotInspect` page) stalls at `readyState=0`/`networkState=2` before it can
show the first frame. It plays fine from the dashboard "▶ Watch" (which autoplays
and forces a full load). Adding `-movflags +faststart` to the mux moves `moov`
to the front so previews show the first frame immediately.

## Acceptance criteria

- [ ] Stage-7 render passes `-movflags +faststart` to the final mux.
- [ ] `SnapshotInspect` / preview `<video>` shows the first frame promptly (no indefinite spinner).
- [ ] No regression in render size/quality or YouTube upload.

## Dependencies
