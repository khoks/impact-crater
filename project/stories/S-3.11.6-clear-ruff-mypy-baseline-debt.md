## Description

As a contributor, I want `ruff check`, `ruff format --check` and `mypy --strict` to pass over the whole tree, so that S-3.11.2's CI can gate PRs on them instead of inheriting a red baseline. Measured on 2026-10-25 with the lock-pinned tools (ruff 0.15.12, mypy 1.20.2): `ruff check backend tests scripts` reports ~175 violations (39 I001 unsorted imports, 16 RUF002 / 13 RUF003 / 5 RUF001 ambiguous unicode in docstrings and comments, 13 E402, 13 SIM105, 12 UP037, 10 F401, 5 RUF046, 4 B905, 4 E702, 4 N818, …; 83 auto-fixable), `ruff format --check` would reformat 88 of 140 files, and `mypy --strict` finds 68 errors in 24 of 77 files (type-arg, no-any-return, valid-type, arg-type, 11 unused-ignore). The restart audit (`docs/roadmap/LANDSCAPE-AND-PLAN-2026-10-24.md` §4.3 item 31) assumed these were already enforced; they are configured, not passing. Part of the gap is tool drift (the project was last linted with the ruff / mypy versions of June 2026), so the sweep decides whether to pin the dev tools in `pyproject.toml` `[project.optional-dependencies] dev` to the lock versions or adapt the code to the newer rules.

## Acceptance criteria

- [x] `ruff check backend tests scripts` and `ruff format --check backend tests scripts` exit 0 with the pinned versions — verified by ruff 0.17.1 on `backend/impact_crater tests scripts`: "All checks passed!", 143 files formatted (2026-11-03)
- [x] `mypy --strict` (pyproject `files`) exits 0; no new `# type: ignore` without a reason code — verified by mypy 1.20.2: "Success: no issues found in 76 source files"; the sweep removed 9 unused ignores and added two coded ones (`attr-defined` on `cv2.data`, `no-untyped-call` on google-auth's `Credentials`) (2026-11-03)
- [x] The behaviour-preserving sweep lands in its own PR(s) with the backend suite still green (477 pass as of 2026-10-25); any RUF001/002/003 fix that would strip meaningful Unicode from user-facing text is excluded with a `# noqa` and a reason — verified by 525 passed / 12 skipped; the title-card punctuation map and its test keep their curly quotes and dashes under `# noqa: RUF001`, and `×` `–` `α` `γ` in docstrings are allowed via `allowed-confusables` (2026-11-03)
- [x] `project/README.md` / CLAUDE.md coding-standards wording updated from "no new violations in touched files" to "must be clean" — verified by CLAUDE.md and CONTRIBUTING.md (project/README.md never carried the rule) (2026-11-03)
