**Client constraints the bump must handle (all from the provider docs, 2026-10-25):**

- **`temperature` must not be sent** to Claude 4.7+ models (400 on a non-default value; removed outright in API version `2026-10-21`; Haiku 5.5 docs: "Omit `temperature`, `top_p`, and `top_k`"). Replace `_TEMPERATURE_UNSUPPORTED_MODELS = {"claude-opus-4-8"}` with a data-driven rule (any 4.7+ / 5.x model, or simply stop sending it everywhere — every current pin would be 4.7+).
- **Thinking is on by default** on all 5.x models (always-on on Opus 5.5); control spend with `output_config.effort` (`low` for Tier-S / Tier-M, `high` for the judge). Thinking tokens count toward `max_tokens` and are billed as output — raise `max_tokens` headroom and expect `thinking` blocks in `content` (the client already selects the `tool_use` block by name).
- **Forced `tool_choice` (`any` / `tool`) returns 400** on Opus 5.5 / Sonnet 5.5; the client never sets `tool_choice`, so no change — but the integration test must assert that the model still calls the tool at `effort: low` (add `strict: true` on the tool definitions as the cheap guarantee).
- **New stop reasons:** `refusal` (safety classifiers) and `model_context_window_exceeded` must map to readable failures in `_classify_failure`, alongside the planned model-not-found branch.
- **Tokenizer:** 4.7+ models count ~30 % more text tokens than Sonnet 4.6 — the Tier-M estimate above already includes it; re-baseline the pre-job estimate (S-2.9.18).
- **Gemini:** `thinking_config.thinking_level = MINIMAL` for Tier-S if Gemini is used; `gemini-embedding-2` takes an image `Part` in `embed_content` (google-genai 1.75 is installed) — embedding spaces are incompatible with 001, so the semantic-dedup cosine threshold (0.93, calibrated on caption vectors) must be re-tuned on the Zion fixture (S-2.10.8 / S-3.10.1). Prompt files move to `prompts/<op>/anthropic_claude-haiku-5-5.jinja2` etc.

**Found while deciding — fold into this story:**

- **The two Opus rate cards are 3× too high.** `config/rate-cards/anthropic-claude-opus-4-5-latest.yaml` and `-4-8-latest.yaml` say $15 / $75 per 1M; the official pages say Opus 4.5 and Opus 4.8 are $5 / $25 (Opus 4.1 was $15 / $75). Every judge cost in telemetry, the SW-US `cost_summary.json` ($2.67 for the judge; the run's $18.84 is really ≈ $17.1) and the effort-level cost preview are overstated by the difference. Fix the cards (and `tests/test_rate_cards.py::test_shipped_rate_cards_load`'s list) in this PR.
- **Gemini image tokens are not metered.** Telemetry shows `input_tokens` of 1–12 for `caption_image` / `score_image`, and their `cost_estimate_usd` is the per-tier placeholder from `_ballpark_cost`, so the Tier-S share of every bill is unknown (list price puts it at ≈ $2–3.5 per 2,000-shot job on 2.5 Flash). Read `usage_metadata.prompt_token_count` in `google_client._apply_usage` and fix `_ballpark_cost` (already planned).
- **No current pin is retired or scheduled before 2027-02-17** (sonnet-4-6 not sooner than 2027-02-17; opus-4-8 2027-05-28; gemini-2.5-flash "no shutdown date", access-limited to past users; gemini-2.5-flash-image 2027-03-15; gemini-embedding-001 2028-05-14). The bump is for cost, quality and the embedding fix, not an emergency.
