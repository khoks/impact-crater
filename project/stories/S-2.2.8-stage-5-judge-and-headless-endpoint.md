## Description

Per ADR-0011 Stage 5 + N-001 — single Tier-L Opus call producing the structured `ArcJudgment`. Inputs: `CandidateSet` + brief + target_duration + (optional) music spec. Output: ordered `selected_items` with `placement_position`, `intended_duration_ms`, `role` (opener/scene_set/peak/callback/closer), `notes` per item; plus `arc_reasoning` prose, `confidence`, `open_questions`. The whole pipeline is exposed via `POST /api/jobs/headless` returning the ArcJudgment as JSON.

- [x] `backend/impact_crater/pipeline/stage5_judge.py` — `judge_narrative_arc(router, candidate_set, brief, target_duration_seconds, mode, music_spec) → ArcJudgment`
