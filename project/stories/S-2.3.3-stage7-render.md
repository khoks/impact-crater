## Description

Per ADR-0010 + ADR-0011 Stage 7 + ADR-0012 (standard mode) — ffmpeg subprocess execution from a `RenderPlan`. H.264 / yuv420p / AAC; 1080p / 30fps for 16:9 (D-007 YouTube-friendly defaults). Two-pass `loudnorm` at -16 LUFS / true-peak -1.5 dB / LRA 11. Background music mixed under the entire video; 1.5s fade-in at start; fade-out at target_duration when music is longer than target.

Music-video mode (beat-snap) is M4 — out of scope here.

## Acceptance criteria

- [ ] `backend/impact_crater/pipeline/stage7_render.py` — `render_plan(plan, snapshot_id, audio_path) → RenderResult`
- [ ] Photo clips → `ffmpeg -loop 1 -t <duration> -i photo.jpg ...` segments concatenated via concat demuxer
- [ ] Video clips → trim segments via `-ss/-t` then concatenate
- [ ] Two-pass loudnorm: pass 1 measures, pass 2 applies with measured values
- [ ] 1.5s audio fade-in + fade-out scheduled per ADR-0012 standard mode
- [ ] Subprocess registered with the worker pool so `cancel()` SIGTERMs the ffmpeg child
- [ ] Output written to `snapshots/{snapshot_id}/render.mp4`; `RenderResult` carries duration / output_bytes / ffmpeg_exit_code
- [ ] RenderEvent telemetry emitted on success + failure
- [ ] `tests/test_stage7_render.py` — synthetic plan with 2 photos + tiny WAV → real MP4 written; ffprobe-validated; skipped when ffmpeg binary not available
