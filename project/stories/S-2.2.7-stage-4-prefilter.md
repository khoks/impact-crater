## Description

Per ADR-0011 Stage 4 — deterministic candidate selection. Apply quality floor + dedup-grouping (via Stage-1 perceptual hashes; Hamming ≤ 5 on pHash) + time/location clustering. Output sized to `clamp(input × 30%, floor, ceiling)` where `floor = max(50, target_duration_seconds × 2)` and `ceiling = floor(input_count × 0.80)`. Output `CandidateSet{ items, cluster_metadata, filter_log }`.

## Acceptance criteria

- [ ] `backend/impact_crater/pipeline/stage4_prefilter.py` — `prefilter(media, brief, target_duration, overrides) → CandidateSet`
- [ ] Floor + ceiling math correct for input sizes 30 / 100 / 1000 / 5000 (unit tests across the boundary cases)
- [ ] Quality threshold from Stage 2 score; dedup clusters from Stage 1 pHash; time/location from Stage 3 metadata
- [ ] `filter_log` records why each item made or missed the cut (surfaces in cost-transparency UI later)
- [ ] User-overridable target_size respected; hard-capped within [floor, ceiling]
- [ ] `tests/test_stage4_prefilter.py` — boundary math + filter-log + overrides
