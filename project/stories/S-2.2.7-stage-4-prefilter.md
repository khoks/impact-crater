## Description

Per ADR-0011 Stage 4 — deterministic candidate selection. Apply quality floor + dedup-grouping (via Stage-1 perceptual hashes; Hamming ≤ 5 on pHash) + time/location clustering. Output sized to `clamp(input × 30%, floor, ceiling)` where `floor = max(50, target_duration_seconds × 2)` and `ceiling = floor(input_count × 0.80)`. Output `CandidateSet{ items, cluster_metadata, filter_log }`.

## Acceptance criteria

- [x] `backend/impact_crater/pipeline/stage4_prefilter.py` — `prefilter(media, stage2, stage3, target_duration_seconds, overrides) → CandidateSet`
- [x] Floor + ceiling math correct for input sizes 0 / 30 / 100 / 1000 / 5000 across boundary cases (5 envelope tests + 5 prefilter envelope-clamp tests)
- [x] Quality threshold from Stage 2 score; dedup clusters from Stage 1 pHash (Hamming ≤ 5); time/location buckets from Stage 3 metadata; per-bucket cap = 10
