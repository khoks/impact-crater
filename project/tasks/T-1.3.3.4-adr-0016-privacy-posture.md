## Description

Lock the privacy posture defaults that satisfy A-002 + D-016 (remote-first routing implies images leave device). Three project-level toggles (strip-EXIF, strip-GPS-only, blur-faces). Per user redirect Q7, ADR-0016 also introduces a **privacy-sensitive routing extension** to ADR-0007's static dispatch — when blur-faces is ON AND a local-LLM (per ADR-0008 v1) is available, face-related operations route to the local LLM only, with the remote provider seeing blurred-face variants. Plug-and-play hook in MVP, functional in v1 when the local LLM lands. Filed as N-011 novel mechanism.

User redirects (2026-05-03):
- Q7 blur-faces default = **OFF**. When user turns it ON, face-related features (N-008 person-library recognition; demographics extraction in D-009 schema) are skipped by default — UI surfaces the trade-off. Plus: **privacy-sensitive routing** — if blur-faces ON AND local-LLM connected, suggest offloading face-related ops to local. Plug-and-play "set it on for remote but use local."
- Q8 strip-GPS-only as a separate toggle from full-EXIF-strip. Some users want timestamps preserved for narrative ordering.
